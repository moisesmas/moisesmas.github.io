Quin sistema d'arxius?

Marca els requisits del teu cas i mira quins sistemes d'arxius els compleixen. Cada ✖ o ⚠ t'explica el límit que descarta l'opció.

Constructor de taules MBR i GPT

Construïx la taula de particions d'un disc amb MBR o amb GPT. Afig particions i comprova els límits: 4 entrades, una sola estesa, lògiques dins de l'estesa i els 2 TiB de l'MBR.

Noms de discos i particions

Mira com es diuen les teues particions en Linux (/dev/sdX#) i en Windows (lletres d'unitat), segons el tipus de disc.

Esquema de particions per a Linux

Indica les característiques de l'equip i obtín un esquema de particions per a Linux amb EFI, arrel, /home i swap.

Arrancada dual: Windows i Linux

Descobrix què passa segons l'ordre d'instal·lació de Windows i Linux, i ordena els passos d'un dual boot.

La cadena d'arrancada del sistema operatiu

Recorre pas a pas el que passa des que el firmware acaba el POST fins a la pantalla d'inici de sessió, i què falla en cada pas.
