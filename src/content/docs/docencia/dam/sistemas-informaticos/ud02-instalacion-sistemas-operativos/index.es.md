Esta unidad te enseña a instalar un sistema operativo de manera planificada, desde elegirlo y preparar el disco hasta dejarlo actualizado y con los controladores correctos. También aprenderás a trabajar con máquinas virtuales, que serán tu laboratorio de pruebas el resto del curso.

## Qué vas a aprender

- Identificar los elementos funcionales de un sistema informático y las funciones y la arquitectura de un sistema operativo.
- Comparar sistemas operativos según los requisitos, las características, el campo de aplicación y la licencia.
- Elegir el sistema de archivos adecuado (FAT32, exFAT, NTFS, ext4) para cada uso.
- Planificar una instalación: requisitos, copia de seguridad y creación del medio de arranque.
- Diseñar la tabla de particiones de un equipo (MBR o GPT, primarias, extendidas y lógicas) y configurar un dual boot.
- Instalar y actualizar sistemas operativos libres y propietarios, cliente y servidor.
- Instalar, desinstalar y actualizar aplicaciones, y diagnosticar controladores.
- Aplicar técnicas de recuperación del sistema.
- Usar la virtualización para instalar y probar sistemas, y documentar todos los procesos.
