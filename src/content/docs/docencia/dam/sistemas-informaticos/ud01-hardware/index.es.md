Esta unidad te muestra qué hay dentro de un ordenador y por qué importa cada pieza, desde la placa base y la CPU hasta la red del aula. Aprenderás a leer características técnicas, a elegir componentes compatibles para un uso concreto y a trabajar con el hardware con seguridad.

## Qué vas a aprender

- Reconocer los componentes físicos de un sistema informático y cómo se conectan entre sí: placa base, CPU, RAM, almacenamiento, fuente de alimentación y puertos.
- Clasificar los tipos de memoria y explicar la función de cada una: registros, memoria caché, RAM y almacenamiento.
- Explicar qué ocurre desde que pulsas el botón de encendido hasta que arranca el sistema operativo y encontrar la causa cuando un equipo no arranca.
- Clasificar, instalar y configurar periféricos.
- Distinguir los tipos de redes, sus componentes y las topologías más habituales.
- Interpretar mapas físicos y lógicos de una red local.
- Trabajar en el taller con seguridad: prevención de riesgos laborales y descargas electrostáticas.
- Elegir componentes compatibles y razonados según el uso que se les vaya a dar.
