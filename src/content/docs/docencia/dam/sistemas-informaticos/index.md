## Presentació

- **Cicle i curs:** 1r de Desenvolupament d'Aplicacions Multiplataforma (CFGS DAM), curs 2026-27.
- **Mòdul:** Sistemes Informàtics, codi 0483.
- **Modalitat:** semipresencial.
- **Idioma del material:** valencià, amb versió en castellà de tot el contingut.

Este mòdul t'explica com funcionen per dins els equips i les xarxes sobre els quals treballaràs: el maquinari, la instal·lació i l'administració dels sistemes operatius, l'automatització amb scripts, les xarxes locals, els serveis de xarxa bàsics i la seguretat. Qui programa aplicacions necessita entendre on s'executen, i este mòdul t'ho ensenya fent-ho tu mateix, amb pràctiques i màquines virtuals.
