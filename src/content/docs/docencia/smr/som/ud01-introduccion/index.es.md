Esta unidad te da el mapa de todo el módulo. Verás de qué está hecho un sistema informático, qué hace un sistema operativo entre tú y el hardware, cómo guarda un ordenador texto y números usando solo ceros y unos, y qué reglas debes seguir cuando instalas software.

## Qué vas a aprender

- Identificar los elementos funcionales de un sistema informático: hardware, software, datos y usuarios.
- Reconocer los componentes básicos del hardware y los tipos de periféricos, y decir qué hace cada uno.
- Distinguir el software de sistema, el software de aplicación, el software de programación y el firmware.
- Clasificar los ordenadores (superordenadores, mainframes, servidores, PC, estaciones de trabajo y sistemas empotrados) y asociar cada uno a un uso típico.
- Explicar qué es un sistema operativo, enumerar sus funciones y describir su estructura (monolítica, por capas y modular).
- Clasificar los sistemas operativos actuales según varios criterios: estructura, usuarios, multitarea, licencia y número de CPU.
- Convertir números entre binario, decimal y hexadecimal, y explicar cómo ASCII, Unicode y UTF-8 convierten caracteres en bytes.
- Medir la información con unidades SI e IEC y entender por qué tu disco de 1 TB no muestra 1 TB.
- Comprobar que un ordenador es adecuado para un sistema operativo, elegir un sistema operativo para un trabajo y respetar las licencias de software.

## Mapa de la unidad

1. [El sistema informático](/docencia/smr/som/ud01-introduccion/01-computer-systems/es/): hardware, software, datos y usuarios, los tipos de software y los tipos de ordenadores.
2. [Los sistemas operativos](/docencia/smr/som/ud01-introduccion/02-operating-systems/es/): qué es un SO, sus funciones, su estructura, los SO actuales, cómo clasificarlos y cómo elegir uno.
3. [Representación de la información](/docencia/smr/som/ud01-introduccion/03-data-representation/es/): binario, hexadecimal, ASCII, Unicode, UTF-8 y unidades de información.
4. [Licencias de software](/docencia/smr/som/ud01-introduccion/04-software-licences/es/): software libre y propietario, los principales tipos de licencia y cómo leer una.
5. [Actividades](/docencia/smr/som/ud01-introduccion/actividades/es/): siete actividades, desde tus propios dispositivos hasta elegir un sistema operativo para un caso real.
