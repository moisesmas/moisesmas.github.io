Lab 1 · Why do computers use zeros and ones?

A computer can only distinguish two states

Inside the processor there are billions of transistors. Each one works like a switch: it lets current through or it does not. We call that smallest state, 0 or 1, a bit (binary digit).

Why two states and not ten

A real signal has noise, but that does not matter: everything above the threshold is a 1 and everything below it is a 0. With two states that are far apart, the computer almost never makes a mistake. With ten voltage levels, a little noise could turn a 6 into a 7.

With n bits, how many combinations are there?

Combinations82³ = 8

Every bit you add doubles the number of combinations. With 8 bits (one byte) there are 256: numbers from 0 to 255.

Switch on bulbs and make a number click on each bulb

Binary00000000 Decimal0 Hexadecimal00 Octal0
All off = 0
Each position is worth double the one on its right: 1, 2, 4, 8, 16, 32, 64, 128. The number is the sum of the bulbs that are on. Try "Shift left ←": moving all the bits one position to the left multiplies by 2, just as adding a zero in decimal multiplies by 10.
Lab 2 · Positional number systems

One quantity, four ways to write it

A number system is a set of symbols and some rules for combining them. In positional systems, the value of each digit depends on where it is. The base tells you how many symbols there are and how much each step in position is worth.

Binary · base 2

The language of hardware. Weights: 1, 2, 4, 8, 16…

Octal · base 8

A shorthand for binary, 3 bits at a time. It is used in Linux permissions.

Decimal · base 10

The one we use, because we have ten fingers. Weights: 1, 10, 100…

Hexadecimal · base 16

A shorthand for binary, 4 bits at a time. When we run out of digits, we continue with letters: A=10 … F=15.

The odometer what happens when we run out of symbols?

Look at the binary: when a digit reaches its maximum value (1 in binary, 7 in octal, 9 in decimal, F in hexadecimal), it goes back to 0 and carries one to the next position. This is exactly what we do when we go from 9 to 10. When we reach 255, the 8 bits are full, and the next number "overflows" and goes back to 0.

Break a number down by position

General rule, the fundamental theorem of numeration: each digit is multiplied by the base raised to its position (starting at 0 on the right), and everything is added up. The little squares show how many times the weight of each column is repeated.

Lab 3 · Converting from one system to another

Three methods that cover every case

From any base to decimal: add up the weights (tab 2). From decimal to another base: repeated division. Between binary, octal and hexadecimal: group the bits, without going through decimal.

Decimal → another base: repeated division

Read the remainders from bottom to top: the last remainder is the most significant digit.

Binary ↔ octal and hexadecimal: grouping

Octal: groups of 3 bits (2³ = 8), starting from the right
Hexadecimal: groups of 4 bits (2⁴ = 16), starting from the right

The pale zeros are padding: they are added on the left to complete the last group and do not change the value. To go the other way, replace each octal digit with its 3 bits or each hexadecimal digit with its 4 bits.

Lab 4 · Where you will come across these bases

Everything ends up as bits

The computer stores everything in binary: text, colours, network addresses, permissions. We use hexadecimal and octal because they are short ways of writing that binary.

Screen colours web, design, CSS

R255
G140
B0
#FF8C00

Each channel is 1 byte (0–255). A byte is 8 bits and is written with exactly 2 hexadecimal digits. That is why web colours have 6 digits: 3 bytes, 24 bits, 16,777,216 colours.

Text is numbers too ASCII and UTF-8

Every character has a code. Basic letters take up 1 byte (ASCII). Characters such as ñ, á or an emoji take up 2, 3 or 4 bytes in UTF-8: they appear with a dashed border.

IP addresses networks, an SMR module

An IPv4 address is 32 bits divided into 4 octets of 8 bits. Each number goes from 0 to 255 because it is one byte. Subnet masks (255.255.255.0) can only be understood properly in binary.

Linux permissions chmod uses octal

chmod 754rwxr-xr--

Each group of permissions is 3 bits (read=4, write=2, execute=1), which is exactly what fits in one octal digit. chmod 755 means 111 101 101.

Lab 5 · Measuring information

From the bit to the terabyte

The bit (lowercase b) is the smallest unit. The byte (uppercase B) is 8 bits and is the unit used to measure storage. From there we use prefixes: kilo, mega, giga, tera…

The ladder of units

1 bita 0 or a 1. One bulb.
1 nibble4 bits. One hexadecimal digit.
1 byte8 bits. One text character, one colour channel.
1 KB1,000 bytes. A paragraph of text.
1 MB1,000 KB. A whole book in plain text.
1 GB1,000 MB. A short film in normal quality.
1 TB1,000 GB. A typical home hard drive.
1 PB1,000 TB. Data centres.

Here we use the International System of Units (SI): each step is ×1000. In tab 6 we will see why ×1024 is sometimes used.

bit or Byte: watch the capital letter

Network speeds are measured in bits per second (Mbps, Mb/s). Files are measured in bytes (MB). That is why a "600 Mbps" fibre connection does not download at 600 MB per second.

Lab 6 · The confusion between two units

Why does my 1 TB drive only have 931 GB?

Because "kilo" has been used with two different meanings. In the International System, kilo = 1000. But computers work with powers of 2, and 2¹⁰ = 1024 is very close to 1000, so for decades 1024 bytes were called a "kilobyte".

Simulator: buy a drive

Manufacturer · SI ×1000
1 TB
Windows · ×1024 (calls it "GB")
931 GB
"Missing"69 GB
Not a single byte is missing. Both numbers describe the same bytes: the manufacturer divides by 1000 and Windows divides by 1024. The correct thing would be for Windows to show "931 GiB".

The error grows with every prefix

With kilo the difference is only 2.4%, and nobody worried. With terabyte drives it is already almost 10%, enough to cause complaints and even lawsuits against manufacturers.

The "bi" in kibi, mebi, gibi comes from binary: kilo-binary, mega-binary, giga-binary. It is written with an i in the middle: KiB, MiB, GiB.

How this mix-up came about

1960s–70s

Memory chips are built in powers of 2. As 1024 ≈ 1000, computer people say "kilo" for convenience.

1980s–90s

With megas and gigas the approximation gets worse. Some manufacturers use ×1000 and others ×1024. A "1.44 MB" floppy disk mixed both: 1.44 × 1000 × 1024 bytes.

1998

The IEC (International Electrotechnical Commission) creates the binary prefixes: kibi, mebi, gibi. Kilo goes back to meaning only 1000.

2008

The ISO/IEC 80000-13 standard includes them. It is the standardised, correct form.

Today

Both habits exist side by side. You need to know which one each program uses.
