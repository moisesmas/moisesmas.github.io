## What you will learn

:::pasos

- What you **may do** with each type
- How to **find and respect** a licence
:::

---

## Software is protected by copyright

:::pasos
- Software is a **creative work**, like a book or a song
- In Spain and the EU, the author owns the **exclusive rights**
- Copy, distribute and modify: **only with permission**
:::

---

## A licence is a contract

A **software licence** gives you permission to use a program, under conditions:

:::pasos
- **Who** can use it: a person, a company, non-commercial only
- **How many** devices or users
- **For how long**: forever, a subscription, a trial
- Whether you can see, modify, copy or sell the **source code**
:::

---

## Piracy has real costs

:::caution[Piracy has real costs]
A paid program without a licence is **copyright infringement**: fines, claims and, in serious cases, criminal penalties.

Cracked programs also spread **malware** and get no official updates.

A technician is **responsible** for the licences of the computers they manage.
:::

---

## Free software: four freedoms

| Freedom | Meaning |
|---|---|
| **0** | Run the program for **any purpose** |
| **1** | **Study** how it works and **change** it (needs the source code) |
| **2** | **Redistribute** copies |
| **3** | Distribute your **modified** versions |

---

## Free means freedom, not price

:::pasos
- Free software **can be sold**
- A program that costs nothing is **not necessarily** free software
- The **FSF** defines free software; the **OSI** defines open source
- Different point of view, similar goals: most licences fit both
- People write **FOSS**: free and open-source software
:::

## Proprietary software

:::pasos
- The owner **keeps the rights**
- You get the **right to use** it under an **EULA** (End-User Licence Agreement)
- No source code, **no modifying**, no redistributing
- Examples: **Windows, Microsoft Office, Adobe Photoshop**
:::

---

## Proprietary licensing models

| Model | How it works |
|---|---|
| **OEM** | Pre-installed with a new computer; tied to it |
| **Retail** | Bought separately; one device at a time |
| **Volume** | One agreement for many installations |
| **Subscription** | Pay every month or year to keep using it |

Always read the **EULA**: the rules depend on the product.

---

## Freeware, shareware and freemium

:::pasos
- **Freeware**: free of charge, **closed** source; may limit use ("non-commercial")
- **Shareware / trial**: limited time or features, then you **pay**
- **Freemium**: free basic version, **paid** advanced features
- None is free software: **no source code**
:::

---

## Copyleft or permissive

| | Copyleft | Permissive |
|---|---|---|
| Idea | Freedom must be **preserved** | Do **almost anything** |
| Condition | **Same licence** and source code | Keep the notice and licence text |
| Licences | GNU **GPL** | **MIT, BSD, Apache 2.0** |
| Examples | Linux kernel, GIMP, WordPress, Blender | FreeBSD, Apache HTTP Server, Node.js |

---

## Licences in the middle

:::pasos
- **MPL** (Mozilla Firefox, LibreOffice)
- Share the changes made to the **licensed files**
- You may **mix** them with other code
:::

---

## Creative Commons is for content, not software

:::note[Creative Commons is for content, not software]
For texts, images, music and videos. Four conditions: **BY** (name the author), **NC** (non-commercial), **SA** (same licence), **ND** (no derivatives).

For software, use a licence designed for code: **GPL** or **MIT**.
:::

---

## What can I do with each licence?

| Licence type | Read and modify the code | Share copies | Share your changes |
|---|---|---|---|
| **Proprietary (EULA)** | No | No | Not applicable |
| **Freeware** | No | Only if the author allows | Not applicable |
| **Shareware / trial** | No | Often yes, unchanged | Not applicable |
| **Copyleft (GPL)** | Yes | Yes | **Yes**, same licence |
| **Permissive (MIT, BSD, Apache)** | Yes | Yes | **No**, keep the notice |

---

## Three common mistakes

:::pasos
1. **"Free of charge" is not "free software"**: freeware gives no freedoms
2. **"Open source" is not "not commercial"**: companies sell support and hosting
3. **"I downloaded it, so I may use it"**: check the conditions of use
:::

---

## Before you install a program: five questions

:::pasos
1. **Who is the author?** Download from the official source
2. **Where is the licence text?**
3. **What does it allow?** Use, devices, users, duration
4. **Do I need a record?** Keep an **inventory of licences**
5. **Is there a free alternative?**
:::

---

## Where to find the licence text

:::pasos
- In the **installer**
- In the **About** or **Help** menu
- In a `LICENSE` or `COPYING` file
- Debian and Ubuntu: `/usr/share/doc/<package>/copyright`
- Alternatives: **LibreOffice**, **GIMP**, **Linux**; compare compatibility, support and training
:::

## Summary

- Software is protected by **copyright**; the **licence** says what you may do
- **Free software**: four freedoms; free means **freedom**, not price
- **Proprietary**, **freeware**, **copyleft**, **permissive**
- **Copyleft** keeps the same licence; **permissive** only asks for the notice
- Read the licence and keep an **inventory**
