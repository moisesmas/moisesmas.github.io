This unit gives you the map of the whole module. You will see what a computer system is made of, what an operating system does between you and the hardware, how a computer stores text and numbers using only zeros and ones, and which rules you must follow when you install software.

## What you will learn

- Identify the functional elements of a computer system: hardware, software, data and users.
- Recognise the basic hardware components and the types of peripherals, and say what each one does.
- Tell system software, application software, programming software and firmware apart.
- Classify computers (supercomputers, mainframes, servers, PCs, workstations and embedded systems) and match each one to a typical use.
- Explain what an operating system is, list its functions and describe its structure (monolithic, layered and modular).
- Classify current operating systems by several criteria: structure, users, multitasking, licence and number of CPUs.
- Convert numbers between binary, decimal and hexadecimal, and explain how ASCII, Unicode and UTF-8 turn characters into bytes.
- Measure information with SI and IEC units and understand why your 1 TB disk does not show 1 TB.
- Check that a computer is suitable for an operating system, choose an operating system for a job and respect software licences.

## Map of the unit

1. [The computer system](/docencia/smr/som/ud01-introduccion/01-computer-systems/): hardware, software, data and users, the types of software and the types of computers.
2. [Operating systems](/docencia/smr/som/ud01-introduccion/02-operating-systems/): what an OS is, its functions, its structure, current OSes, how to classify them and how to choose one.
3. [Data representation](/docencia/smr/som/ud01-introduccion/03-data-representation/): binary, hexadecimal, ASCII, Unicode, UTF-8 and units of information.
4. [Software licences](/docencia/smr/som/ud01-introduccion/04-software-licences/): free and proprietary software, the main types of licence and how to read one.
5. [Activities](/docencia/smr/som/ud01-introduccion/actividades/): seven activities, from your own devices to choosing an operating system for a real case.

## Laboratories

Two interactive labs go with the unit. The **Bit Lab** is for binary, hexadecimal, conversions and units. The **Computer System Explorer** is for everything else: system parts, the inside of a PC, software types, computer types, the layers of an OS, kernel architectures, OS classification and licences.
