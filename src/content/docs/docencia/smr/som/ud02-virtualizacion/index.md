From now on, almost every practice in this module will happen inside a virtual machine. This unit shows you what a virtual machine is, how to create and configure one, and how to use it safely, so that you can experiment without breaking the real computer.

## What you will learn

- Explain the difference between a real machine and a virtual machine, and between host and guest.
- List the advantages and disadvantages of virtualization and decide when it is a good idea.
- Distinguish Type 1 and Type 2 hypervisors, give examples of each and explain how VT-x and AMD-V help.
- Install virtualization software (free and proprietary) and create virtual machines from free and proprietary operating systems.
- Configure a virtual machine: CPU, memory, disk, firmware and network mode.
- Deploy a virtual appliance from an OVA file and understand the OVF and OVA formats.
- Use snapshots as a safety net, and know why they are not a backup.
- Install Guest Additions and use the shared clipboard and shared folders.
- Measure CPU, memory and disk performance on the host and in the guest, and explain the difference.
