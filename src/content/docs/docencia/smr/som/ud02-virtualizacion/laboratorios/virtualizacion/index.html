Virtualization Playground

Physical vs virtual

Each physical server usually works far below its capacity. Choose how many servers the company has and see what changes when you group them as virtual machines on a few hosts. The numbers are a simple model, not real data.

Pros & cons

Read each situation and decide if it is an advantage or a disadvantage of virtualization. After each answer you will see which concept is behind it.

Hypervisor stack builder

A Type 1 hypervisor runs on the hardware; a Type 2 hypervisor is a program that runs on an operating system. Build the stack of layers in the right order and then classify real products.

VT-x on/off

A guest cannot simply run privileged instructions. See how each method solves it and what happens if hardware virtualization is switched off in the UEFI.

Resource allocator

The host has limited resources. Create the machines, move the sliders and watch the warnings. Notice how a dynamic disk grows when the guest writes data and does not shrink when it deletes it.

New VM wizard

A simulated wizard like the one in VirtualBox. Choose the guest system and check your values against the minimum requirements of the system and the limits of the host (8 cores, 16 GB of RAM).

Network modes

Choose a network mode and see who the virtual machine can talk to. A solid line means that both sides can start a connection; a dashed line means that only the VM can start it.

Practice

New exercises every time, with instant feedback. Choose an answer and read the explanation.
