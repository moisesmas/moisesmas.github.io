Starvation and aging

A long process L (burst 5) arrives at time 1. Short processes (burst 2) arrive every 2 units, starting at 0. With SJF the long process is always overtaken. With aging, every 2 units a process waits, its effective length is reduced by 1.

    Critical section and deadlock

    A. Two processes, one printer

    P1 and P2 want to print a four-line report each. You decide which process runs the next instruction. Without a lock the lines get mixed. With a lock, the printer is a critical section: the other process goes to Waiting.

    B. Deadlock

    Two resources, the printer (R1) and the scanner (R2). P1 asks for R1 and then R2. P2 asks for R2 and then R1. Alternate the steps (P1, P2, P1, P2) and watch the graph. A solid arrow from a resource to a process means assigned; a dashed arrow from a process to a resource means waiting for it.

      The four conditions of a deadlock

      1. Mutual exclusion: a resource has only one user at a time.
      2. Hold and wait: a process keeps what it has while it waits for more.
      3. No preemption: a resource cannot be taken away.
      4. Circular wait: P1 waits for P2 and P2 waits for P1.

      Input/output manager

      A. Polling, interrupts or DMA?

      A device sends some words to memory. Each row shows what the CPU does in each time unit. Simplified model: copying a word or running an interrupt handler costs 1 unit.

      W = CPU waiting (busy), C = CPU copies a word, F = CPU free for other processes, H = interrupt handler, S = CPU starts the DMA transfer.

      B. Cache

      Read blocks from a slow disk. A hit in the cache costs 1 unit; a miss costs 10. The cache removes the least recently used block when it is full.

      C. Spooling

      Send print jobs. The printer prints one page every moment. With spooling, jobs wait in a queue and you can keep working. Without it, the program is blocked while the printer works.
