## Overview

- **Cycle and year:** Microcomputer Systems and Networks (SMR), 1st year, 2026/2027.
- **Module code:** 0222.
- **Hours:** 133 in total.
- **Language of the material:** English. Every page also has a Spanish version.

This module is about the software that makes a computer work: the operating system. You will learn what an operating system does, how to install and configure Windows and Linux, and how to manage them with graphical tools and with the command line. You will practise in virtual machines, so you can try things without breaking a real computer.

A technician must install, configure and look after operating systems every day. This module gives you that base for the rest of the cycle.

## What you will learn

The module has five learning outcomes (RA). You must pass all five.

- **RA1 (13 %).** Describe how a computer system and its files work: data representation, processes, file systems, attributes and permissions.
- **RA2 (24 %).** Install operating systems: check the hardware, choose the system, plan the installation, set up the boot manager, solve problems, respect licences and keep the system updated.
- **RA3 (23 %).** Do basic configuration: user interfaces, personal settings, installing and removing programs, updates, system recovery and automatic tasks.
- **RA4 (27 %).** Do basic administration: users and groups, processes, services, memory, disks, shared resources and system logs.
- **RA5 (13 %).** Create and use virtual machines: real and virtual machines, hypervisors, configuration and performance tests.

## How you are assessed

Each unit has its own mix of instruments:

| Unit | Objective tests | Classroom activities | Observation and peer learning |
|---|---|---|---|
| 1 and 3 | 60 % | 30 % | 10 % |
| 2, 4, 5 and 6 | 70 % | | 30 % |
| 7 and 8 | 80 % | 10 % | 10 % |
| 9 | 90 % | | 10 % |

- **Practices:** you work in real or virtual machines. Your teacher may also use quizzes, rubrics, a portfolio and reports.
- **Hand-written summary:** in units 1 and 3 you hand in a hand-written summary of the theory before the test. No summary: -1 point on the test. Satisfactory: no change. Above expectations: +1 point, if the test mark is at least 4. In units 4 to 9 the teacher may ask for it.
- **Minimum marks:** the test mark must be at least 4, the average of the practices must be at least 4, and the final mark, with all weights applied, must be at least 5.
- **Key outcomes:** you must pass all five learning outcomes.
- **Recovery:** it takes place in the ordinary call. You only retake the blocks you did not pass. If you lost the right to continuous assessment, you take a test on the whole course.
- **Practices to hand in:** at least 80 % in the ordinary call and 100 % in the extraordinary call.
- **Extraordinary call:** a test on the whole module. You may also have to hand in extra practical work and explain it in person to the teacher. If you do not attend, you do not pass the module.
